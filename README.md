# Smart-Obstacle-Avoiding-Robot-Car
Designed and developed a smart autonomous robot car using Arduino. The system uses an ultrasonic sensor to detect obstacles in real time and automatically decides the optimal path to avoid collisions.  Technologies Used: Arduino, Ultrasonic Sensor (HC-SR04), L298N Motor Driver, Embedded C  
Key Highlights:
• Real-time distance measurement and decision logic
• Automated obstacle detection and path selection
• Hands-on experience in hardware integration and system troubleshooting

This project strengthened my problem-solving, logical thinking, and data-driven decision-making skills, which I now apply in my Data Analytics journey.
